## Project
- VUS-OS is a Windows-style desktop in the browser. Main file: `index.html` (repo root). Local folder: `E:\Claude\VUS OS`.
- Repo: GitHub `Cra-Z-Gaming/VUS-OS`, branch main. NOT served by GitHub Pages: everything is fetched from raw.githubusercontent.com, so service workers and extra same-origin files can't be relied on.

## Known limits (by design for now)
- Python `input()` needs a browser that can pause WebAssembly (recent Chrome / Edge); elsewhere it ends with EOF.
- A JavaScript program stuck in a tight loop can only be ended with Stop / Ctrl+C (the worker is terminated).
- A `|` inside code splits the Terminal line; use `;` instead.
- Python `urllib` and `requests` work through `pyodide-http` (patched when the code mentions them). The server must allow CORS, including the `Authorization` header.
- Terminal output stops at 3000 lines; files over 1 MB and non-text files are not given to programs; programs can't delete files or folders.
- Folder websites: `location.href = "page2.html"` can't be intercepted (use `<a>` links); `new URL("a.png", location.href)` fails; cyclic `import`s can't be wired; only the top page gets the helper; files beyond the first 1500 (`SITE_MAX`) in the tree are not reachable from scripts; compressed Unity builds (.br / .gz) are not served with the right encoding; the page runs in the OS's own origin.
- Git language: no merges, stash, tags, submodules, hosts other than github.com, or `--amend`.
- Islamic holiday dates can be a day off from the user's local moon sighting.
- Apps that use IndexedDB or Cache Storage fail inside the VM (the sandbox has none); Python can't be installed inside the VM.
- Notes, Calculator and Clock: the Clock's timer and alarms only work while its window is open.
