# VUS-OS
Web OS version of VUS Hub, This OS combines VUS Hub apps & OS-only apps like terminal

why use VUS-OS? 
- better for those who like personalization
- most apps launch within the OS, which is easier to manage instead of multiple real tabs on your computer
- you can multitask multiple tabs, which could be nice if you like reading chat while playing a game
- cuz its cool and is password protected (optional)
- you can export / import the OS. The export can save all files and data like VUSL games/game data. you could also save your logins (protected by passkey)
- vus OS has its own terminal which is built in, with a few external languages like git, py, and js, which are very useful for those who code or cant access github
- the only reason why you wouldnt want to use vus OS is because its made with ai (everything is made with ai now days :(
